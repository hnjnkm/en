# OPIc 문법과 단어

별도 설치나 빌드가 필요 없는 정적 학습 페이지입니다. `index.html`을 브라우저로 열거나 다음 명령으로 실행하세요.

```sh
cd /workspace/en
python -m http.server 8000
```

- 문법 18개: 문장 구조, 동사, 시제, 질문, 명사, 비교, 전치사, 문장 연결 등
- 단어·표현 64개: 일상, 집, 취미, 여행, 음식, 감정, 문제 해결, 답변 연결
- 메뉴별 무작위 퀴즈, 주제 필터, 검색, 브라우저에 저장되는 복습 표시

콘텐츠는 `content.js`, 화면과 동작은 `index.html`, `style.css`, `app.js`에 있습니다. 퀴즈는 문법 최대 10문제, 단어는 선택한 주제에서 최대 10문제입니다. 검색은 학습 목록에만 적용되고 퀴즈는 메뉴/주제를 기준으로 출제됩니다. 복습 표시는 사용 중인 브라우저에 저장되며 다른 기기와 동기화되지 않습니다.

티어표 디자인의 Pretendard 폰트와 단색 배경, 얇은 구분선, 최소한의 글자 크기 및 굵기를 사용했습니다. 폰트 라이선스는 `fonts/OFL.txt`를 참조하세요.

배포 시 이 디렉터리의 정적 파일을 함께 게시하세요. GitHub Pages에 배포할 때도 빌드가 필요하지 않습니다.
