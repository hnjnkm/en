# OPIc 문법과 단어

별도 설치나 빌드가 필요 없는 정적 학습 페이지입니다. `index.html`을 브라우저로 열거나 다음 명령으로 실행하세요.

```sh
cd /workspace/en
python -m http.server 8000
```

문법은 학습 순서에 따른 32개 강의입니다.

1. 문장 기초: 문장 성분과 5형식, be동사, 수 일치, 부정문, 질문, 대명사
2. 명사와 수식: 가산성, 관사, 수량, 형용사·부사, 비교, 전치사
3. 시제: 현재·과거·진행·미래·현재완료·현재완료진행·과거완료
4. 동사 확장: 조동사, 정중한 요청, 부정사·동명사, used to, 수동태, there/it
5. 문장 연결: 이유·대조, 시간절, 간접질문, 관계절, 조건문, 명령·제안, 구동사

각 강의는 개념 설명, 형태표, 예문 3개와 구조 분석, 오류 2개와 수정 이유, 해설이 있는 연습 문제 2개, 발화 과제와 답변 예시로 구성됩니다. 문법 문제는 총 64개이며 강의 안에서 직접 풀거나 선택한 단계에서 무작위 10문제 퀴즈로 복습할 수 있습니다. 퀴즈 결과에서 오답 해설을 다시 보고 해당 강의로 이동할 수 있습니다.

단어·표현 64개는 일상, 집, 취미, 여행, 음식, 감정, 문제 해결, 답변 연결 주제로 나뉩니다. 검색은 설명·예문을 포함한 학습 목록에 적용되고 퀴즈는 선택한 메뉴/단계/주제를 기준으로 출제됩니다. 복습 표시는 현재 브라우저에만 저장됩니다.

콘텐츠는 `content.js`, 화면과 동작은 `index.html`, `style.css`, `app.js`에 있습니다. 티어표와 같은 Pretendard 폰트, 단색 배경, 얇은 구분선과 3가지 글자 크기·한 가지 굵기를 사용합니다. 폰트 라이선스는 `fonts/OFL.txt`를 참조하세요.

GitHub Pages는 `main` 브랜치의 루트에서 배포됩니다. `.nojekyll`은 정적 파일을 그대로 게시하도록 합니다. `.github/workflows/pages.yml`은 변경 시 브랜치 배포를 요청하고 사이트가 실제 학습 페이지를 응답하는지 확인합니다.
