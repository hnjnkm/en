# OPIc 문법과 단어

별도 설치나 빌드가 필요 없는 정적 학습 페이지입니다. `index.html`을 브라우저로 열거나 다음 명령으로 실행하세요.

```sh
cd /workspace/en
python -m http.server 8000
```

문법은 학습 순서에 따른 33개 강의입니다.

1. 문장 기초: 문장 성분과 5형식, be동사, 자동사·타동사, 수 일치, 부정문, 질문, 대명사
2. 명사와 수식: 가산성, 관사, 수량, 형용사·부사, 비교, 전치사
3. 시제: 현재·과거·진행·미래·현재완료·현재완료진행·과거완료
4. 동사 확장: 조동사, 정중한 요청, 부정사·동명사, used to, 수동태, there/it
5. 문장 연결: 이유·대조, 시간절, 간접질문, 관계절, 조건문, 명령·제안, 구동사

각 강의는 개념 설명, 형태표, 예문 3~5개와 구조 분석, 오류 2~3개와 수정 이유, 해설이 있는 연습 문제 2~4개, 발화 과제와 답변 예시로 구성됩니다. 문법 문제는 총 68개이며 강의 안에서 직접 풀거나 선택한 단계에서 무작위 10문제 퀴즈로 복습할 수 있습니다. 퀴즈 결과에서 오답 해설을 다시 보고 해당 강의로 이동할 수 있습니다.

문법 사이드 목차는 33개 강의로 바로 이동하고 현재 읽는 강의를 표시합니다. 검색이나 단계 필터로 강의가 숨겨져 있어도 목차에서 선택하면 해당 강의를 펼쳐 이동합니다. 모바일에서는 하단의 접이식 목차를 사용하며, `#g17` 같은 주소로 강의를 직접 열 수도 있습니다.

단어·표현은 중복 표제어를 제외한 1,216개이며, 그중 공백 없는 표제어는 1,152개입니다. 사람·가족, 집, 여행, 교통, 음식, 일, 공부, 감정 등 30개 주제로 나뉩니다. 모든 항목에 한국어 뜻과 자연스러운 사용 표현이 있습니다. 처음의 64개에 있던 문장·번역도 유지합니다.

- 목록은 한 페이지에 30개씩 표시하며, ‘섞기’로 현재 범위의 순서를 바꿀 수 있습니다.
- ‘알아요/아직 몰라요’ 표시와 전체·모르는 단어·아는 단어 필터를 제공합니다. 처음 보는 단어는 모르는 단어에 포함됩니다.
- 카드는 먼저 뜻을 떠올린 뒤 뜻과 사용 표현을 확인합니다. 상태를 표시하면 다음 카드로 넘어가며, 한 회차가 끝나면 현재 조건에 남은 단어를 다시 섞습니다. 모르는 단어 필터에서는 이미 아는 단어를 제외합니다.
- 단어 퀴즈는 주제·상태·검색 범위에서 최대 10개를 출제합니다. 틀린 단어는 모르는 단어로 표시하고, 정답 확인 후 직접 상태를 변경할 수도 있습니다.
- 학습 상태는 현재 브라우저의 localStorage에만 저장됩니다. 기존 단어 복습 표시도 새 ‘알아요’ 상태로 읽어옵니다. 브라우저 저장이 차단된 경우 세션 내 상태만 유지하며 안내를 표시합니다.

문법 퀴즈는 선택한 학습 단계에서 출제합니다.

콘텐츠는 `content.js`, 화면과 동작은 `index.html`, `style.css`, `app.js`에 있습니다. 티어표와 같은 Pretendard 폰트, 단색 배경, 얇은 구분선과 3가지 글자 크기·한 가지 굵기를 사용합니다. 폰트 라이선스는 `fonts/OFL.txt`를 참조하세요.

GitHub Pages는 `main` 브랜치의 루트에서 배포됩니다. `.nojekyll`은 정적 파일을 그대로 게시하도록 합니다. `.github/workflows/pages.yml`은 변경 시 브랜치 배포를 요청하고 사이트가 실제 학습 페이지를 응답하는지 확인합니다.
