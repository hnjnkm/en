# oPIC

별도 설치나 빌드가 필요 없는 정적 학습 페이지입니다. `index.html`을 브라우저로 열거나 다음 명령으로 실행하세요.

```sh
cd /workspace/en
python -m http.server 8000
```

문법은 서아쌤 강의에 대해 사용자가 제공한 목차를 따라 **8개 Unit + 말하기 보충, 47개 강의**로 구성합니다. 자동 생성 자막은 보조로 참고하며, 설명·예문·해설은 자체 학습 자료입니다. 원본 강의: https://www.youtube.com/watch?v=3hm7qJDcHCM

1. 명사·대명사: 명사 모양·자리·복합명사, 가산·불가산, 사람·활동 명사와 어미 예외, 인칭·재귀·지시·부정대명사
2. 동사(수·태·시제): 수 일치, 능동·수동과 4·5형식, 시제 지도, 현재·현재완료·과거·과거완료·미래·미래완료·진행
3. 형용사·부사: 명사 수식과 보어, 수량 표현, 헷갈리는 형용사, 부사 위치·빈도·초점·수량
4. 전치사·등위·부사절: 핵심 전치사, 대등·병렬·상관접속사, 시간·이유·조건·양보·목적
5. 명사절·형용사절: that·whether·if·의문사절, 관계대명사 격·소유·생략·비제한적 관계절
6. 접속부사·전접부: 문장 사이 논리와 문장부호, 전치사·접속사·부사 구조 비교
7. 준동사: to부정사의 세 역할·가주어·동사 결합, 동명사·관용 표현·파생명사와의 차이, 분사 전치·후치 수식
8. 분사구문·비교구문: 축약 부사절·행위자·능동·수동·완료, 원급·비교급·최상급·강조·비교 대상

말하기 보충에는 기존 문장 성분·be동사·자동사/타동사·조동사·명령·관사·부정·질문·정중한 요청·used to·there/it·조건 가정·구동사 자료를 유지합니다. 기존 `#g01`~`#g33` 주소와 복습 상태 키는 유지하며 화면의 학습 번호만 새 순서에 맞춥니다.

각 강의는 개념 설명, 형태표, 예문과 구조 분석, 오류와 수정 이유, 해설이 있는 연습 문제, 발화 과제와 답변 예시로 구성됩니다. 강의 안에서 직접 풀거나 선택한 단계에서 무작위 10문제 퀴즈로 복습할 수 있습니다. 퀴즈 결과에서 오답 해설을 다시 보고 해당 강의로 이동할 수 있습니다.

문법·단어 전환은 페이지 최상단의 고정 네비게이션에서 언제든 할 수 있습니다. 스크롤하거나 퀴즈를 푸는 중에도 메뉴가 보이며, 퀴즈 중 다른 메뉴를 선택하면 퀴즈를 닫고 해당 학습 화면으로 이동합니다.

문법 사이드 목차는 47개 강의로 바로 이동하고 현재 읽는 강의를 표시합니다. 검색이나 단계 필터로 강의가 숨겨져 있어도 목차에서 선택하면 해당 강의를 펼쳐 이동합니다. 문법과 단어 모두 화면 폭 768px 이상에서는 왼쪽 목차를 항상 펼쳐 표시합니다. 그보다 좁은 휴대폰 화면에서는 하단의 접이식 목차를 사용하며, `#g17` 같은 주소로 강의를 직접 열 수도 있습니다.

단어에도 같은 사이드 목차가 있습니다. 묶음 보기에서는 성격별로 정리된 100개 묶음을 펼쳐 이동하며 읽는 위치를 표시합니다. 기본 목록·카드에서는 30개 주제를 선택해 복습 범위를 바꿉니다. 모바일 목차는 선택 후 접힙니다. 검색·성격·상태 조건 때문에 선택한 묶음이 숨겨진 경우 해당 묶음을 볼 수 있도록 조건을 정리합니다. `#wg87`은 가산·불가산 허가·문서 비교, `#wg93`은 복합명사 구조, `#wt01`은 첫 단어 주제로 바로 들어가는 주소입니다.

단어·표현은 중복 표제어를 제외한 1,216개이며, 그중 공백 없는 표제어는 1,152개입니다. 사람·가족, 집, 여행, 교통, 음식, 일, 공부, 감정 등 30개 주제로 나뉩니다. 모든 항목에 한국어 뜻과 자연스러운 사용 표현이 있습니다. 처음의 64개에 있던 문장·번역도 유지합니다.

- 목록은 한 페이지에 30개씩 표시하며, ‘섞기’로 현재 범위의 순서를 바꿀 수 있습니다.
- ‘알아요/아직 몰라요’ 표시와 전체·모르는 단어·아는 단어 필터를 제공합니다. 처음 보는 단어는 모르는 단어에 포함됩니다.
- 카드는 먼저 뜻을 떠올린 뒤 뜻과 사용 표현을 확인합니다. 상태를 표시하면 다음 카드로 넘어가며, 한 회차가 끝나면 현재 조건에 남은 단어를 다시 섞습니다. 모르는 단어 필터에서는 이미 아는 단어를 제외합니다.
- 단어 퀴즈는 주제·상태·검색 범위에서 최대 10개를 출제합니다. 틀린 단어는 모르는 단어로 표시하고, 정답 확인 후 직접 상태를 변경할 수도 있습니다.
- 학습 상태는 현재 브라우저의 localStorage에만 저장됩니다. 기존 단어 복습 표시도 새 ‘알아요’ 상태로 읽어옵니다. 브라우저 저장이 차단된 경우 세션 내 상태만 유지하며 안내를 표시합니다.

문법 퀴즈는 선택한 학습 단계에서 출제합니다.

단어의 기본 화면은 성격별 **100개 묶음**이며 총 1,054개 학습 항목(표현 표기 기준 1,033개)이 있습니다. 같은 단어·표현이 다른 학습 목적의 묶음에 다시 등장할 수 있으므로 1,216개 기본 단어에 이 수를 더해 고유 단어 수로 계산하지 않습니다.

- 명사의 성격 8개: 불가산명사, 가산 대체어, 의미에 따른 가산성, 사람·활동·사물 명사, 복수 전용 명사, 불규칙 복수
- 단어 가족 8개: 동사·명사·형용사·부사 변화, 부정 접두사, 형용사 접미사
- 동사의 결합 10개: to부정사, 동명사, 의미 변화, 목적어 뒤 구조, 구동사, 목적어·전치사, 동사·명사 결합
- 전치사 조합 10개: 동사·형용사·명사와 전치사, 시간·장소 대비
- 헷갈리는 단어 8개: 듣기·말하기·이동·돈·학습, 비슷한 철자, 상태·장소·수량
- 뜻의 관계 8개: 반의어, 평가를 구체화하는 표현, 정도·빈도, 명사·동사·형용사 결합
- 형태와 불규칙 6개: 동사의 세 형태, 감정 형용사, 비교급·최상급
- 말하기 표현 6개: 시간 순서, 이유·결과·대조, 의견·선호, 문제 해결, 묘사·회상, 정중한 요청
- 어미와 품사 22개: -al·-ive·-ing 명사, 명사 어미, -ly 형용사, 같은 철자의 여러 품사, 형태·발음 차이와 복수
- 가산·불가산 비교 6개: 허가·문서, 사람·활동, 물건·설비, 정보·생각, 일·음식, 같은 명사의 의미별 가산성
- 복합명사 8개: 명사 수식 구조, 일·회사, 여행·교통, 집·물건, 음식·쇼핑, 건강·환경, 기술·학습, 복수 규칙

각 묶음에 뜻·사용 표현과 필요한 차이 설명이 있습니다. 성격·상태·검색으로 좁히고, 묶음별 카드 또는 퀴즈로 복습할 수 있습니다. ‘섞기’는 묶음과 내부 항목의 순서를 바꾸고, 선택한 묶음 카드에서는 그 묶음의 남은 항목을 섞습니다. 기본 목록·카드 기능도 그대로 사용할 수 있습니다. 묶음별 표현은 `word-groups.js`에서 관리합니다. 문법 문제는 총 151개입니다.

콘텐츠는 `content.js`, 화면과 동작은 `index.html`, `style.css`, `app.js`에 있습니다. 가산명사·불가산명사 강의(`#g07`)에는 관사·수량·뜻별 가산성·유사 명사 비교표가 있습니다. 명사 구조(`#g34`)와 사람·활동 명사·어미 예외(`#g35`)를 별도로 제공하며, 복합명사의 중심 명사와 복수, `occupation`의 직업 뜻과 소유 한정사도 설명합니다. 어미는 단서이며, 수동·분사는 목적어·전치사구 유무만으로 확정하지 않도록 주요 예외를 명시합니다.

사이트 이름은 **oPIC**이며 탭 제목·상단 로고·홈 화면 이름·공유 메타데이터에 적용합니다. 파비콘은 검정 바탕에 흰색 원을 그린 `favicon.svg`이며, ICO(16·32·48px)와 홈 화면용 PNG(180px)도 제공합니다. 티어표와 같은 Pretendard 폰트, 단색 배경, 얇은 구분선과 3가지 글자 크기·한 가지 굵기를 사용합니다. 폰트 라이선스는 `fonts/OFL.txt`를 참조하세요.

GitHub Pages는 `main` 브랜치의 루트에서 배포됩니다. `.nojekyll`은 정적 파일을 그대로 게시하도록 합니다. `.github/workflows/pages.yml`은 변경 시 브랜치 배포를 요청하고 사이트가 실제 학습 페이지를 응답하는지 확인합니다.
